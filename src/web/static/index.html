How to use
  • Type or paste a transliteration below, including spaces.
  • Click to mark a position you want restored, or click anywhere in the text box and press it again for another one. Leave none and a random 15% of positions get auto-masked instead.
  • Use x for a single sign of unclear reading and ... for a gap of unknown length -- both are read as context only. Our model predicts one sub-word token at a time, so unlike Aeneas's own arbitrary-length restoration, an unknown-length gap is not itself restored, only marked.
  • A tablet photo is optional and only ever affects the provenience head.
